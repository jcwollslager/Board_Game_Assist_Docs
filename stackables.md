# Overview
Stackables can be around 90% of board game components, and so are likely to be the most common component you work with when using BG Assist.

These encompass a lot of categories of real-world components, such as cards, tokens, tiles, and so on, which all have properties which make them useful to group together in this way:
* Two primary faces, typically referred to as the face and back of the component, though sometimes referred to as front/back, top/bottom, etc.
* Typically kept in some kind of stack, be that a deck of cards, a pillar of tokens, and so on.
* Typically found in some standardized shape that is shared across all of the components, be that a rectangle, circle, or polygon. (Support for custom SVG shapes coming soon!)

If the component you're looking to make follows those criteria, then a stackable component is for you!
